# pyrlyn.dev QA, 2026-10-17

Live https://www.pyrlyn.dev tested with headless Chrome at 360, 390 and 1440 px. All 155 sitemap
URLs were crawled at 360 px. The code review covered `main` at 1957334. PR #6 (earlier QA) is
merged; its items are not repeated here.

## Result

- Every crawled page returns 200, has one `<h1>`, no duplicate ids, no broken `#anchors`, no
  images without `alt`, no horizontal scroll, no console errors, no failed requests.
- `/#faq`: lands 96 px from the top, below the 72 px sticky header. The 5 FAQ items open and
  close with click and Enter, and several can be open at once.
- `npm run build`, `check` (0 errors), `check:docs`, `check:seo` and `test` (10/10) pass.
- External links in the built docs: all return 200 except the two below.

## Bugs

### 1. No security headers (not fixed: hosting config)
- **Severity:** low
- **Steps:** `curl -I https://www.pyrlyn.dev/`.
- **Expected:** `Strict-Transport-Security`, `X-Content-Type-Options`, `Referrer-Policy`, CSP.
- **Actual:** none are sent (Cloudflare in front, no custom headers).
- **Suggested fix:** add a Cloudflare Transform Rule, or a `public/_headers` file if the host
  reads it.

### 2. `www` and apex both serve 200 (not fixed: hosting config)
- **Severity:** low
- **Steps:** `curl -sI https://pyrlyn.dev/` and `https://www.pyrlyn.dev/`.
- **Expected:** one host redirects to the other.
- **Actual:** both return 200. Canonical and sitemap use the apex, which limits the SEO impact.
- **Suggested fix:** 301 `www` to the apex, or the reverse, in Cloudflare.

### 3. Docs link to an unpublished crate (not fixed: synced content)
- **Severity:** low
- **Steps:** open the link `https://crates.io/crates/rtok-plugin-sdk` from the rtok docs.
- **Expected:** a crate page.
- **Actual:** 404. The text comes from pyrlyn/rtok through sync-docs.
- **Suggested fix:** publish the crate, or drop the link in pyrlyn/rtok.

### 4. Docs reference `http://localhost:3000` / `:16686` (informational)
- **Severity:** info
- **Actual:** these are example local addresses in docs, not real links; link checkers flag them.

### 5. Long title and description (not fixed: synced H1)
- **Severity:** low
- **Actual:** `/swarfr/docs/ecosystems/` title is 76 characters (limit 70) and its description is
  171 characters (limit 170). `check:seo` warns about both.
- **Suggested fix:** shorten the H1 in pyrlyn/swarfr.

### 6. Docs nav gaps (not fixed: by design)
- **Severity:** low
- **Actual:** ketch `uk/REGISTRY.md` and `uk/TROUBLESHOOTING.md` are not in `docs-nav.json`, so
  they render under "More".
- **Note:** translated docs (ru, uk) are not in the nav by design, so they render under "More".
  The same warning appears for rtok and the other products. Fixing it needs a localized nav
  design, not two entries.


### 7. `/favicon.ico` returns 404 (fixed)
- **Severity:** info
- **Actual:** the page declares SVG and PNG icons, so browsers are fine. Only crawlers that
  request `/favicon.ico` directly see a 404.
